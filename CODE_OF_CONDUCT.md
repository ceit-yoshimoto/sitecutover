# Code of Conduct

Be respectful, specific, and constructive.

This project welcomes contributions from people with different experience levels and backgrounds. Technical disagreement is expected; personal attacks, harassment, discriminatory behavior, threats, and deliberate disruption are not acceptable.

When reviewing work:

- criticize the code or idea, not the person
- explain tradeoffs and evidence
- assume good intent while remaining clear about requirements
- protect contributors' and users' private information

Maintainers may edit, hide, or remove participation that violates these expectations and may restrict repeated abusive behavior.
